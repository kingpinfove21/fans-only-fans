# Fans Only Fans

HNG15 Lesson 2 — eCommerce website for a demo fan shop.

## Features
- Product listing and detail pages
- Add to cart, checkout
- Google authentication
- Persistent order history (Supabase)
- Confirmation emails (Mailgun)

## Tech Stack
- Next.js 15 + TypeScript + Tailwind CSS
- Supabase (database + auth)
- Mailgun (email)
- Vercel (hosting)

## Setup
1. Clone the repo
2. Run `npm install`
3. Create `.env.local` with Supabase and Mailgun keys
4. Run `npm run dev`
5. Open `http://localhost:3000`
